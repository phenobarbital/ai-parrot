# TASK-2338: The shared catalog fixture, and the ratchet that reads it

**Feature**: FEAT-448 — field-type-catalog-reconciliation
**Spec**: `sdd/specs/field-type-catalog-reconciliation.spec.md` §5.5, AC7
**Status**: pending · **Priority**: high · **Effort**: M
**Depends-on**: TASK-2332, TASK-2335, TASK-2336

## Context

This is the deliverable that stops the feature recurring. Everything else in
FEAT-448 is paying off one instance of a divergence that went unnoticed for
three months because nothing compared the two catalogs.

The failure mode to design against is specific: a ratchet that compares our
enum to a SECOND list we also maintain is just the third list that drifts. The
client half (navigator-svelte FEAT-515 AC7) must be able to read the truth from
here rather than from a copy.

## Scope

- Publish the catalog as data, not only as a Python enum — the natural home is
  the existing `GET /api/v1/form-controls` response, which the client already
  consumes to build its palette. Adding the value-shape contract per type makes
  it the single source both sides can assert against.
- A test here asserting the served catalog matches `FieldType` exactly, in both
  directions.
- Record for the client half how to fetch it in CI without a running server (a
  committed snapshot regenerated by a script is acceptable; a hand-maintained
  copy is not — the difference is that the snapshot has a generator and fails
  when stale).

## Acceptance Criteria

- AC1 A test fails if a `FieldType` value is missing from the served catalog.
- AC2 A test fails if the served catalog names a type not in `FieldType`.
- AC3 The client half can obtain the catalog without hand-copying it, and the
  mechanism is documented in this task's completion note.
- AC4 The snapshot, if one is used, has a regeneration command and a test that
  fails when it is stale.

## Notes

Deliberately not: a shared package between the repos. That is a larger change
than the problem justifies and would couple release cycles further than the
"both halves ship together" rule already does.

## Context

Spec §3 Module 5, item 2. `.agents/agents/` (Google host) has 9 agents; `sdd-coder` (dispatched by the
`sdd-worker` orchestrator), `code-reviewer` and `qa-runner` (dispatched by `sdd-autopilot`) exist only for
Claude. This task ports them to AGY's agent format and ships them through the asset pipeline.

**How assets ship (not stated in the spec):** `packages/ai-parrot/src/parrot/sdd/_assets/manifest.json` and
every `_assets/` copy are **generated** by `scripts/sdd/check_asset_sync.py --write` from the glob rules in its
`ASSET_SOURCES`; `tests/sdd_scripts/test_check_asset_sync.py::test_repo_assets_in_sync` fails on any drift.
The existing rule `(".agents/agents/sdd-*/agent.md", ("google",))` covers `sdd-coder` but **not**
`code-reviewer`/`qa-runner`, so two rules are added. Shipped text must pass the asset gates: no `packages/`,
`scripts/`, `PYTHONPATH=`, `tests/sdd_scripts/` strings (`MONOREPO_PATH_RE`/`MONOREPO_TEXT_RE`), and no
`CLAUDE.md`, Jira-style keys other than `FEAT-`/`TASK-`, or branch literals such as `origin/dev`
(`parrot.sdd.audit`, `test_assets_have_no_publication_findings`).

## Implementation Notes

### Adaptation rules (from spec §3 M5 / `docs/sdd/AGY.md`)
- Tools: `Bash -> run_command`, `Read -> view_file`, `Write/Edit -> write_file/edit_file`,
  `Agent -> invoke_subagent`, `TaskStop -> manage_subagents(Action="kill")`.
- Every multi-step shell snippet uses the resolved **absolute** worktree path, or assigns `WT=<abs path>` in the
  same command before `cd "$WT" && …` / `git -C "$WT" …`: each `run_command` is a fresh shell.
- Keep each agent's role and output contract unchanged (`sdd-coder` still ends with the `DevelopmentOutput` JSON;
  `qa-runner` still writes `.autopilot/qa-report.md` with `verdict: PASS | FAIL`; `code-reviewer` stays bound to
  the `codex` reviewer seat where the Claude version is — spec non-goal).

"""FEAT-847 M5 — Google (agy) sub-agent assets."""

from __future__ import annotations

import re
from pathlib import Path

import pytest

from parrot.sdd.installer import install_sdd_integration, load_manifest, sdd_status

NEW_AGENTS = ("sdd-coder", "code-reviewer", "qa-runner")
REPO_ROOT = Path(__file__).resolve().parents[4]


@pytest.fixture
def google_repo(tmp_path: Path) -> Path:
    import subprocess

    subprocess.run(["git", "init", "-q"], cwd=tmp_path, check=True)
    install_sdd_integration(tmp_path, hosts=("google",))
    return tmp_path


def test_manifest_includes_all_google_agents(google_repo: Path) -> None:
    targets = {e["target"]: e["hosts"] for e in load_manifest()}
    status = sdd_status(google_repo)["hosts"]["google"]
    for name in NEW_AGENTS:
        target = f".agents/agents/{name}/agent.md"
        assert targets[target] == ["google"]
        assert (google_repo / target).is_file()
        assert target in status["current"]

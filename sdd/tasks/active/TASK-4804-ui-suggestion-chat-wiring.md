JSON body; this task carries them onto `AgentMessage`, renders `SuggestionChips` under assistant bubbles (hidden
while streaming and for user messages), and routes clicks: `action == "explain"` → existing `handleExplain`;
otherwise → `handleSend(prompt, undefined, output_mode)`, the normal chat path. One task for the three files
(spec Worktree Strategy: shared UI files serialized).

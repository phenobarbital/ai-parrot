## Implementation Notes

- One string, four places: the fast path matches `sys.argv[1:]` **exactly**, so the argv list, the bare
  constant, the baked suffix and the agent line must agree token for token.
- The fast path's budget (≤ 5 ms, TASK-4509) is unchanged: it still imports only `worktree_environment`.
- `_assets` is never hand-edited: run `python scripts/sdd/check_asset_sync.py --write`, then `--check`.
- The `_classify_hook_command` behaviour (`bare` / `baked` / `other`) is unchanged; a repo installed with the
  old line now classifies as `other` → `parrot self doctor --sdd` says "re-run `parrot sdd install`", which is
  the C25 contract working as designed. Note it in the Completion Note.

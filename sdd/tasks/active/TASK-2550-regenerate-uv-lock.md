## Implementation Notes

### Key Constraints
- ALWAYS `source .venv/bin/activate` first.
- Prefer `uv lock` over `uv lock --upgrade` — upgrading unrelated pins is a
  separate concern and will bloat the review.
- A bare `uv sync` **uninstalls** tree-sitter grammars and leiden from the dev
  venv; always finish with `uv sync --extra wiki`.
- `rustworkx` wheels are abi3 and need only `numpy` — no build tooling required.

### Verification script
```bash
source .venv/bin/activate
{
  uv lock
  git diff --stat uv.lock
  uv sync
  uv pip show rustworkx networkx pathspec
  wikitoolkit status; echo "wikitoolkit status exit=$?"
  python -c "import parrot.knowledge.wiki.cli; print('import OK')"
  uv sync --extra wiki
} 2>&1 | tee artifacts/logs/feat-471-uv-sync.log
```

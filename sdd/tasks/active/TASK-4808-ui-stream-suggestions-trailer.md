## Context

Spec rev 0.3, §3 Module 8 (UI half), G8, Q1. Today `consumeStream` yields `done` only at EOF and `AgentChat`
commits the final message only after the `for await` loop ends, so even with a server trailer (TASK-4807) the bubble
would finish late. This task makes the parser frame-aware (each NUL starts a JSON frame), lets AgentChat finish the
bubble on `done`, and patches chips onto it when the `suggestions` frame arrives. The agent stream request opts in
with `suggestions_trailer: true`.

---

## Scope

- `stream.ts`: `StreamChunk` gets `{ type: "suggestions"; suggestions: AgentChatSuggestion[]; turn_id?: string }`;
  `consumeStream` yields `done` when the 2nd NUL arrives (or at EOF), then `suggestions` for a trailer frame.
- `AgentChat.svelte`: send `suggestions_trailer: true` in the agent stream payload; on `done`, swap the pending
  bubble for `finalMessage` immediately (and clear `streamingMessageId`); on `suggestions`, patch that message.
- Tests: extend `stream.test.ts` and `AgentChat.test.ts`; pytest wrapper `tests/ui/test_vitest_suggestion_stream_trailer.py`.

**NOT in scope**: `streamChatWithBot` callers' behaviour (parser change is backward compatible: a single frame still
yields `done` at EOF); ChatService persistence of chips (live turn only); server code.

## Implementation Notes

- JSON text never contains a raw NUL (it is escaped as `\u0000`), so splitting frames on NUL is safe.
- Keep `done` at EOF for single-frame streams (old servers, bot chat) — existing `stream.test.ts` cases must pass
  unchanged.
- Ignore trailing frames that are not objects with a `suggestions` array (e.g. the handler's late
  `{"error": ...}` frame) — log nothing, yield nothing.
- In AgentChat keep the after-loop `if (finalMessage)` block as the single place that saves/titles/opens canvases;
  the `done` branch only swaps the visible bubble early. The `suggestions` branch must update both `messages` and
  the `finalMessage` local so the after-loop save includes chips (they are still not reloaded — live-turn only).

## Implementation Notes

- **`worker` is a move, not a rewrite**: same options, same `base_env = dict(os.environ)` snapshot *before*
  importing `parrot.flows` (FEAT-768's navconfig `.env` rule), same `LaunchError` → exit-code mapping. The eight
  FEAT-768 tests must pass with only the argv prefix changed.
- **`brief` / `fix` are the same skeleton without the worker policy**: primary checkout (both slash commands
  provision their own worktree), `--setting-sources project,local`, `--model <_DEFAULT_MODEL>`, forwarded
  Claude args, and the slash command text as the final positional. No `--agent`, no `--settings` JSON, no
  sandbox preflight, no tmux. Everything after the subcommand's own arguments is forwarded verbatim into the
  slash-command text so `/sdd-brief` / `/sdd-fix` keep owning their grammar.
- Build the prompt with `" ".join(...)` — it is a Claude prompt, not a shell line; do not `shlex.quote`.
- `scripts/sdd/launch_worker.sh` stays (monorepo alias, not shipped) and only its message changes.

### `packages/ai-parrot/src/parrot/flows/dev_loop/feature_launcher.py` (MODIFY)
```python
# occurrences: 1 (verified @8c634436b9: grep -c '^def main(argv: Sequence\[str\] | None = None) -> int:' …/feature_launcher.py)
# BEFORE — insert above `def main(argv: Sequence[str] | None = None) -> int:`
def launch_session(
    initial_prompt: str,
    *,
    cwd: Path,
    claude_args: Sequence[str] = (),
    base_env: Mapping[str, str] | None = None,
) -> int:
    """Open an interactive Claude session in ``cwd`` with ``initial_prompt`` as its first message (C26 item 5).

    Used by ``parrot sdd launch brief|fix``: no agent, no sandbox settings, no tmux — identical to typing the
    slash command by hand, except that the operator environment (``base_env``, captured before ``parrot`` was
    imported) is what Claude starts from. Returns 1 when ``claude`` is not on PATH; otherwise never returns.
    """
    claude = shutil.which("claude")
    if claude is None:
        print("launch: missing host prerequisite(s): claude", file=sys.stderr)
        return 1
    command = [claude, "--setting-sources", "project,local", "--model", native_claude_sandbox._DEFAULT_MODEL,
               *claude_args, initial_prompt]
    env = dict(os.environ if base_env is None else base_env)
    os.chdir(cwd)
    os.execvpe(command[0], command, env)
    return 1
```
**Why**: mirrors the tail of `native_claude_sandbox.launch_worker` (:772-780) minus the worker policy.

```python
from __future__ import annotations

import os

import click

_PASSTHROUGH = {"ignore_unknown_options": True, "allow_interspersed_args": False}


@click.group(name="launch")
def launch() -> None:
    """Start an SDD cycle interactively: a sandboxed feature worker, a brief, or a ledger fix session."""


@launch.command("worker", context_settings={"ignore_unknown_options": True})
# FILL IN: paste the option/argument decorators and the body of FEAT-768's `launch_worker_cmd` unchanged
#          (feature, --tmux, --detach, --sandbox, --sandbox-allow-domain, --no-upstream, claude_args) — bounded by AC-1.
def worker(...) -> None:
    """Prepare FEATURE and launch its sdd-worker console."""


def _session(ctx: click.Context, prompt_words: list[str], claude_args: tuple[str, ...]) -> None:
    base_env = dict(os.environ)  # snapshot BEFORE importing parrot.flows (navconfig loads .env secrets on import)
    from parrot.flows.dev_loop import feature_launcher  # noqa: PLC0415

    cwd = feature_launcher.resolve_primary_checkout(feature_launcher._invocation_dir())
    ctx.exit(feature_launcher.launch_session(" ".join(prompt_words), cwd=cwd, claude_args=claude_args, base_env=base_env))


@launch.command("brief", context_settings=_PASSTHROUGH, add_help_option=False)
@click.argument("source")
@click.argument("rest", nargs=-1, type=click.UNPROCESSED)
@click.pass_context
def brief(ctx: click.Context, source: str, rest: tuple[str, ...]) -> None:
    """Open a Claude session running `/sdd-brief SOURCE [flags…]` in the primary checkout."""
    _session(ctx, ["/sdd-brief", source, *rest], ())


@launch.command("fix", context_settings=_PASSTHROUGH, add_help_option=False)
@click.argument("rest", nargs=-1, type=click.UNPROCESSED)
@click.pass_context
def fix(ctx: click.Context, rest: tuple[str, ...]) -> None:
    """Open a Claude session running `/sdd-fix [issue-id | --top N …]` in the primary checkout."""
    _session(ctx, ["/sdd-fix", *rest], ())
```
**Why this shape**: `brief`/`fix` forward everything after their own argument into the slash-command text
(C26 item 5), so `/sdd-brief` / `/sdd-fix` keep their grammar; Claude args for brief/fix are intentionally not
separable in v1 (`FILL IN` if a `--` separator is wanted: split `rest` at the first `--`, bounded by AC-3).

## Context

Spec §3 Module 12 (U1, option a) — media delivery. Presigned figure URLs minted by the procedures
answer service (TASK-3723) must travel on the response object without being coerced to `Path`, because
`AIMessage.images` / `media` are `List[Path]` and `parse_response` drops any entry whose `path.exists()` is
False (spec §6 "Does NOT Exist": no URL-typed media field today). This task adds two validated
http(s)-only string lists to **both** `AIMessage` and `AgentResponse`, and syncs them from the wrapped
`AIMessage` inside `AgentResponse.sync_documents_and_paths`. Implements AC14 (model half). Parallelism:
no dependency — only task touching `models/responses.py`.

---

## Scope

- Add `image_urls: List[str]` and `media_urls: List[str]` (default empty list) to `AIMessage`, right after
  the `media` field.
- Add the same two fields to `AgentResponse`, right after its `media` field.
- Add one shared `field_validator("image_urls", "media_urls")` per model that raises `ValueError` unless
  every item starts with `http://` or `https://` (no `data:`, no filesystem paths).
- Extend `AgentResponse.sync_documents_and_paths` to copy `self.response.image_urls` / `media_urls` into
  its own lists (dedup, preserve order, **in-place append** — see Implementation Notes).
- Write `test_aimessage_url_fields_validate` and an `AgentResponse` sync test.

**NOT in scope**: `parse_response` / `ParsedResponse` (TASK-3716); any channel wrapper (TASK-3717/3718/3719);
changing `images`/`media`/`files`/`documents` types or defaults; `AIMessageFactory` signatures.

## Implementation Notes

### Pattern to Follow
Mirror the existing `images` sync loop in `sync_documents_and_paths` (responses.py:1174-1178): iterate the
wrapped `AIMessage` list and `append` items not already present.

### Key Constraints
- Worktree tests: the shared `.venv` is editable-installed against the main checkout, so run tests with
  `PYTHONPATH=packages/ai-parrot/src:packages/ai-parrot-tools/src:packages/ai-parrot-integrations/src pytest <file> -q`.
- No new third-party dependency (spec G8, AC18).
- Google-style docstrings and strict type hints on every function/class; Pydantic v2; `self.logger` / module
  `logging.getLogger(__name__)` — never `print`.
- HTTP is `aiohttp` only — never `requests` / `httpx` (ruff TID251 fails the merge gate).
- Existing `Path` attachment behaviour (`images` / `media` / `files` / `documents`) must stay byte-for-byte
  unchanged (AC14) — URL handling is strictly additive.
- `AgentResponse` has `validate_assignment=True` (line 1131). **Never reassign** `self.image_urls = [...]`
  inside the after-validator — that re-triggers validation (recursion). Mutate in place with `.append`,
  exactly like the existing loops do.
- Field order matters only for readability; field names are fixed by spec §3 M12 (`image_urls`, `media_urls`).
- Validator must accept an empty list and reject `None` items; do not strip/normalise URLs.

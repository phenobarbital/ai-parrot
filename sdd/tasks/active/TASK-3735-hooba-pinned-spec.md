## Implementation Notes

- **Network**: generating the JSON needs one read-only GET to `https://api.hooba.com/api/doc.json` (public, no auth).
  If your sandbox has no network, STOP after writing the code and report the blocker in the Completion Note with the
  exact command for the orchestrator to run: `python -m parrot_tools.hooba.spec.prune --source https://api.hooba.com/api/doc.json --out <path>`.
  Never hand-write or fabricate the document.
- `prune_spec`: keep a path item's operations whose first tag ∈ keep_tags (drop the path when none remain); collect
  `$ref` targets transitively (walk dicts/lists for `"$ref": "#/components/<kind>/<name>"`) and keep only those
  components; drop keys starting with `x-`; set `servers`. Output must be deterministic (sort keys) so the sha is stable.
- `load_pinned_spec(path=None)`: `path or os.environ.get("HOOBA_SPEC_PATH")` overrides the bundled file; the bundled file
  must hash to `PINNED_SHA256` (mismatch → `HoobaSpecError`); an override skips the hash but logs a WARNING with its
  `info.version`; any missing REQUIRED_PATHS entry → `HoobaSpecError`; `info.version != PINNED_VERSION` → WARNING.

## Context

options, checkpointer lifecycle inside `run_flow()`, `suspend()`, and the
`resume()` classmethod that reconstructs a flow from a checkpoint and

## Scope

- Extend `AgentsFlow.__init__` with keyword-only opts (defaults preserve
  byte-identical behavior): `checkpoint: bool = False`,
  `checkpoint_retention: int = FLOW_CHECKPOINT_REDIS_TTL`,
  `checkpoint_history: int = FLOW_CHECKPOINT_HISTORY`,
  `checkpoint_include_responses: bool = False`, `durable: bool = False`,
  `checkpoint_store: str | CheckpointStore | None = None`,
  `durable_store: str | CheckpointStore | None = None`,
  `flow_id: Optional[str] = None` (autogenerated UUID when absent).
- When `checkpoint=True`: validate exportability up front
  (`to_definition()` — fail early with `FlowNotExportableError`), build the
  `FlowCheckpointer`, register its listener, acquire the lease at `run_flow()`
  start, release + `aclose()` in a finally block. Honor `FlowMetadata`
  checkpoint block in `from_definition()` (constructor opts win over metadata).
- Implement `async def suspend(self) -> FlowCheckpoint` — final checkpoint
  `status="suspended"` + `checkpointer.dump()`; usable mid-run and callable
  from the recovery service (TASK-2054).
- Implement `@classmethod async def resume(cls, flow_id, checkpoint_id=None,
  *, agent_registry, store=None, durable_store=None) -> "AgentsFlow"`:
  1. Load checkpoint: durable store first, ephemeral fallback
     (`CheckpointNotFoundError` on miss/expiry).
  2. Acquire lease (raise `FlowLockedError` if held).
  3. Rebuild via `from_definition(checkpoint.definition, agent_registry=...)`.
  4. Seed a fresh `FlowContext`: decode results (+responses when present)
     via serializer, then `mark_completed(node_id, result, response)` for
     each completed node in `completion_order`; restore `shared_data`,
     `initial_task`; re-bind memory refs.
  5. Continue checkpoint numbering from the loaded id.
  6. Return the flow ready for `run_flow(ctx)` — the event-driven scheduler
     naturally executes only the frontier (verify with a counter test).
- Integration tests (spec §4): kill/resume, re-fork, write-through,
  suspend→durable→resume, memory-refs reattach, lease conflict.

**NOT in scope**: recovery service (TASK-2054), HTTP (TASK-2055), docs
(TASK-2056).

## Implementation Notes

### Key Constraints
- **Zero behavior change when `checkpoint=False`** — the existing test suite
  must pass unmodified (spec acceptance criterion #1).
- Lease holder id: `f"{hostname}:{pid}:{uuid4().hex[:8]}"` or similar —
  unique per process attempt.
- `resume()` must NOT re-execute completed nodes: assert via node-execution
  counters in tests (spec §4 `test_resume_skips_completed_nodes`).
- Re-fork (`checkpoint_id=<older>`): seed only nodes completed AT that
  checkpoint; downstream results are discarded (their checkpoint entries
  remain in history untouched).
- A lossy checkpoint on resume → `logger.warning` naming the degraded nodes
  (spec §7 Known Risks).
- Failure to acquire lease must release nothing and leave stores untouched.

# packages/ai-parrot/tests/flows/checkpoint/test_suspend_resume.py
async def test_resume_skips_completed_nodes(fake_checkpoint_store, counting_agents):
    flow = build_linear_flow(counting_agents, checkpoint=True, checkpoint_store=fake_checkpoint_store)
    await run_until_node(flow, "node-2")          # simulate crash after node-2
    resumed = await AgentsFlow.resume("f1", agent_registry=registry, store=fake_checkpoint_store)
    await resumed.run_flow("task")
    assert counting_agents["node-1"].calls == 1   # not re-executed
    assert counting_agents["node-3"].calls == 1   # frontier ran

async def test_resume_locked(fake_checkpoint_store):
    await fake_checkpoint_store.acquire_lease("f1", "other-holder", ttl=60)
    with pytest.raises(FlowLockedError):
        await AgentsFlow.resume("f1", agent_registry=registry, store=fake_checkpoint_store)

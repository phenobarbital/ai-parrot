## Implementation Blueprint

### Steps (in order)
1. Find the candidate — *why*: releases ship weekly.
   ```bash
   curl -s https://pypi.org/pypi/google-genai/json | python3 -c "import json,sys;print(json.load(sys.stdin)['info']['version'])"
   ```
2. Introspect it in an isolated venv (scratchpad, never the shared one) — *why*: only exercised versions are declared:
   ```bash
   D=$(mktemp -d) && uv venv -q "$D/v" && uv pip install -q --python "$D/v/bin/python" "google-genai==<candidate>" \
   && "$D/v/bin/python" -I - <<'PY'
   from google import genai
   from google.genai import types, errors
   c = genai.Client(api_key="x")
   assert hasattr(types, "ThinkingConfig") and hasattr(types, "ComputerUse") and hasattr(types, "CreateCachedContentConfig")
   for p in ("models.generate_videos", "operations.get", "files.download", "interactions.create",
             "live.music.connect", "caches.create"):
       o = c.aio
       for part in p.split("."):
           o = getattr(o, part)
   assert hasattr(c.aio, "aclose") and hasattr(errors, "APIError")
   print("ALL OK", genai.__version__)
   PY
   ```
   If it does not print `ALL OK`, step down one release and repeat. Save the output to `artifacts/logs/feat-798-genai-introspection.log`.
3. Declare the floor in both pyprojects; add a `# FEAT-798:` comment line under the FEAT-688 block (`pyproject.toml:27-33`) with the date and the verified version.
4. `uv lock --upgrade-package google-genai` and then `uv lock --check`; confirm `uv.lock` resolves `== <verified>`.
5. Re-pin the floor test.

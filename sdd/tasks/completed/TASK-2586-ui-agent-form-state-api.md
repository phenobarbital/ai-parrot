## Implementation Notes

- `dirty` = deep-equal(`values`, `original ?? defaults()`) negated; use a
  small structural compare (JSON stringify with sorted keys is acceptable).
- `tabErrors` = count of `errors` keys grouped by `FIELD_TAB`.
- `load()` must tolerate extra fields (`extra="allow"` in `BotAgentItem`)
  and coerce `null` dicts/lists to `{}`/`[]`.
- Provider alias tolerance (§7): `values.llm` may hold an alias not in the
  catalog; do not reject it in `validate()`.

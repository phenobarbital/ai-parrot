## Implementation Blueprint

### Steps (in order)
1. `docker compose -f scripts/spikes/surrealdb_g1/docker-compose.yml up -d` — *why*: pinned server.
2. Run the README command with `--report sdd/state/FEAT-824/g1/report.md` — *why*: the report is
   generated, never hand-written.
3. On an SDK-caused failure, re-run with the fallbacks and keep the run that records them — *why*:
   spec §2 forbids a NO-GO on an SDK defect before the fallbacks are tried.
4. Write the shape test; run it; commit the report, the test and any check fixes.

```python
"""The committed G1 report has the shape spec AC Phase 1 #1 requires."""
from __future__ import annotations

import re
from pathlib import Path

REPORT = Path(__file__).resolve().parents[2] / "sdd" / "state" / "FEAT-824" / "g1" / "report.md"


def test_report_shape() -> None:
    text = REPORT.read_text(encoding="utf-8")
    assert "@sha256:" in text, "image must be pinned by digest"
    for n in range(1, 14):
        assert f"G1-{n:02d}" in text
    assert re.search(r"\*\*Verdict: (GO|NO-GO)\*\*", text)
```

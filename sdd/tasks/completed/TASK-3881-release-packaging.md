## Implementation Notes

### Pattern to Follow
Metadata-only change; the only code is the test update. Keep the existing test style (tomllib on the
package's own `pyproject.toml`).

### Key Constraints
- **Precondition check first**: `grep -rn "import pytesseract\|from pytesseract" packages/ai-parrot-pipelines/src`
  must return nothing — *why*: dropping the requirement while an importer survives would break installs.
  If it returns anything, STOP and report (TASK-3873 did not land as planned).
- `uv lock` only — never `uv sync`, `uv add` or `uv pip install` in the worktree (shared-venv rule in
  `.claude/rules/worktree-management.md` §4). Run it from the worktree root with the venv activated.
- **No unrelated lock refresh** (spec M15): after `uv lock`, `git diff --stat uv.lock` must show only removed
  lines, and `git diff uv.lock` must show exactly the two `pytesseract` lines of the pipelines entry. Any
  other hunk (another package's version, a new resolution) ⇒ `git checkout -- uv.lock`, do NOT commit it, and
  report the drift in the Completion Note — *why*: an incidental upgrade would ship untested dependencies.
- Pin the dependency floor loosely in the test (`startswith("ai-parrot>=")`) — *why*: the exact floor is bumped
  by the release process, which already broke the old exact-string pin (currently failing on dev).
- Version string is exactly `"1.1.0"`; no other field in `version.py` changes.

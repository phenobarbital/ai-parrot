## Implementation Notes

### Key Constraints
- Additive and idempotent only: `ADD COLUMN IF NOT EXISTS`, no data change.
- `ALTER TABLE IF EXISTS` on the table too — because `studio_pool` and the FieldSync runner apply every packaged
  migration to databases that may not have `prompt_library`; a plain `ALTER TABLE` aborts the whole chain there.
- Never write the checksum or `MANIFEST.json` by hand: put a placeholder 64-hex literal in the trailer, then run
  `--stamp`. `stamp_migrations` requires exactly one 64-hex literal in the trailer.

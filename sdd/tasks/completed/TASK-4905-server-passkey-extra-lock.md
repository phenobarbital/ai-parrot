## Context

Spec §3 Module 8 (packaging half), G6, AC10, codex S1. `PasskeyAuth` needs `webauthn` (py_webauthn),
shipped by navigator-auth's `passkey` extra; without it the backend raises `ConfigError` at startup.
The root `uv.lock` currently pins **navigator-auth 0.28.7 with no `webauthn` entry**
(`uv.lock:9689-9690`) while the shared venv has 0.28.9 installed ad hoc — a `uv sync` would silently
remove `PasskeyAuth`. Verified at task time (2026-10-30): navigator-auth 0.28.9 is on PyPI with
`webauthn<3,>=2.0; extra == "passkey"`; webauthn 2.8.0 requires `cryptography>=46`,
`pyOpenSSL>=26`, `cbor2>=5.6.5,<6`, `pyasn1>=0.6.2`, `pyasn1-modules>=0.4.2` — compatible with the
locked `pyopenssl 26.4.0`, `cryptography 50.0.2`, `pyasn1 0.6.4`, `pyasn1-modules 0.4.2`; `cbor2` is
new.

**Exclusive task** (`parallel: false`): it rewrites `uv.lock`, a shared lockfile.

### `packages/ai-parrot-server/tests/test_passkey_packaging.py` (CREATE)
```python
"""FEAT-772 packaging guard: the passkey extra exists, is in ``all``, and the lock carries it."""
from __future__ import annotations

import tomllib
from pathlib import Path

REPO_ROOT = Path(__file__).resolve().parents[3]
SERVER_PYPROJECT = REPO_ROOT / "packages" / "ai-parrot-server" / "pyproject.toml"
UV_LOCK = REPO_ROOT / "uv.lock"


def _extras() -> dict[str, list[str]]:
    data = tomllib.loads(SERVER_PYPROJECT.read_text())
    return data["project"]["optional-dependencies"]


def test_passkey_extra_pins_navigator_auth_passkey() -> None:
    """The extra pulls navigator-auth's passkey extra at the first release that ships PasskeyAuth."""
    assert _extras()["passkey"] == ["navigator-auth[passkey]>=0.28.9"]


def test_all_includes_passkey() -> None:
    """``ai-parrot-server[all]`` installs the passkey extra too."""
    (aggregate,) = _extras()["all"]
    assert "passkey" in aggregate.split("[", 1)[1].rstrip("]").split(",")


def test_lock_resolves_passkey_capable_navigator_auth() -> None:
    """uv.lock pins navigator-auth >= 0.28.9 and contains webauthn."""
    lock = tomllib.loads(UV_LOCK.read_text())
    packages = {p["name"]: p["version"] for p in lock["package"]}
    # FILL IN: assert tuple(int(x) for x in packages["navigator-auth"].split(".")[:3]) >= (0, 28, 9)
    #   and that "webauthn" in packages with a 2.x version — bounded by navigator-auth's `webauthn<3,>=2.0`
    assert "navigator-auth" in packages
```
**Why**: `parents[3]` from `packages/ai-parrot-server/tests/` is the worktree/repo root.

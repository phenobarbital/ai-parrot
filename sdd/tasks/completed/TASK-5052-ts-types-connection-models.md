## Context

Spec §3 Module 5 and AC-11: the admin UI's connection types must be generated from the Pydantic
models (`scripts/generate_ts_types.py` → `ui/schemas/*.json` → `pnpm generate` →
`src/lib/types/generated/*.d.ts`), not hand-written in `integrations.ts`. Every later UI task
(TASK-5053–TASK-5057) imports these generated types. TASK-5035 adds `AuthRequiredEnvelope.retry_safe` and
`ChannelLinkPreview`; TASK-5048 removes `EnableResponse` so the exported set is final.

---

## Scope

- Register seven models in `_models()` of `scripts/generate_ts_types.py`: `IntegrationDescriptor`,
  `ConnectInitResponse`, `DisconnectResponse`, `AuthRequiredEnvelope`, `ChannelLinkPreview`
  (all `parrot.auth.oauth2.models`), `AuthRequiredPayload` (`parrot.auth.credentials`),
  `ConnectionEvent` (`parrot.auth.oauth2.events`).
- Run the exporter and `pnpm generate`; commit the 7 new `ui/schemas/*.json` and 7 new
  `src/lib/types/generated/*.d.ts` files exactly as generated.
- Add a test asserting the seven names are exported.

**NOT in scope**: changing any Pydantic model (that is TASK-5035/TASK-5048); consuming the types in the UI
(TASK-5053+); removing the hand-written interfaces in `integrations.ts` (TASK-5057).

- Generated files are never hand-edited (`codebase-conventions.md`: `src/lib/types/generated/` is produced by `pnpm generate`).
- In a worktree, run the exporter with `PYTHONPATH=$(pwd)/packages/ai-parrot-server/src:$(pwd)/packages/ai-parrot/src`
  (docstring of `generate_ts_types.py`), otherwise it exports the main checkout's models.
- `pnpm generate` needs `packages/ai-parrot-server/ui/node_modules`. If absent in the worktree, do not install
  (shared environments are read-only to worktree agents); stop and report `done-with-issues`.

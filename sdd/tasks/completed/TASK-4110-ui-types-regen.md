## Implementation Notes

### Key Constraints
- **json2ts alias collisions**: new properties (`transformer`, `params`, `input_alias`, `output`) may collide with
  existing flattened aliases, and json2ts disambiguates with numeric suffixes — which can RENAME an alias `types.ts`
  already imports (e.g. `Ops`). After generating, `git diff` the `.d.ts`: if any name imported by `types.ts:9-19`
  changed, update the import to the new generated name (never edit the generated file).
- Run `pnpm` only inside `packages/ai-parrot-server/ui/`; do not `pnpm install` (lockfile is out of scope).

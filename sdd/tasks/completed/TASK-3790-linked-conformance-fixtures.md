## Implementation Notes

### Key Constraints
- Fixture files are **generated, then committed**: write a single `_build_<name>()` function per fixture in
  `test_contract_envelopes.py` and produce the JSON from it (run once, save). The test then asserts the regenerated
  text is byte-equal — never hand-edit the JSON.
- Snapshot timestamps make golden output non-deterministic: build with fixed inputs and set/normalise `snapshot_at`
  to a fixed timezone-aware value (e.g. `2026-09-25T00:00:00+00:00`) before dumping — FILL IN below.
- Locate fixtures via `Path(parrot.outputs.a2ui.linked.__file__).parent / "contract"` (package data, S7) — never a
  repo-relative path.
- Frames used by builders are small in-memory DataFrames (the conftest `activity_frame` has day/visits/program).

### References in Codebase
- `test_all_emitters.py:135-180` — builder conformance test style.
- `tests/outputs/a2ui/test_components_filterbar.py:15-42` — golden byte-equality convention.

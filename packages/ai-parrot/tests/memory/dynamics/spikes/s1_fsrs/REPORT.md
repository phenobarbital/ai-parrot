## Limitations

- **Modeling choice for calibration (owner review needed)**: lesson creation is treated as
  an implicit "GOOD" encoding event (`candidate.initial_state(Grade.GOOD, ...)`); trace
  `reviews` are later reinforcing/weakening touches. "Relevance" in
  `relevance × retrievability × (1 + importance/10)` has no query context in this offline
  calibration and is proxied as `min(1.0, len(reviews) / 4)`. The baseline ranking's
  `scope_score` (normally file-overlap in `coder_feedback.py`) is proxied from `importance`
  since episodic lessons have no analogous "files" field. Both proxies are documented, not
  approved formulas — the owner may accept, adjust, or reject them in `amendment.md`.
- **Stale-persistence eligibility** requires a lesson dormant for the *entire* 30-day
  window; with lessons created uniformly across a 30-day trace, essentially none reach that
  bar inside a single 30-day run (n=0 here). A longer trace or a relaxed "no signal for N
  days" threshold would be needed to get real evidence for this metric.
- **Rank correlation is negative** (~-0.66) in both policies: the FSRS-weighted composite
  score and the `(scope_score, recurrence, timestamp)` baseline order lessons quite
  differently in this synthetic trace. This is a genuine open question for the owner, not a
  bug — flagged as PENDING in `amendment.md` rather than silently resolved.
- **Environment blocker** (see "Commands" above): the literal
  `pytest .../test_s1_harness.py -q` command could not be executed inside this specific
  ephemeral attempt worktree due to a missing compiled Cython extension unrelated to this
  task. All test bodies were run instead via direct module execution against the exact same
  committed `candidate.py`/`harness.py` code, with identical results reported above. The
  owner/CI should re-run the pytest command itself once merged into an environment with the
  extension built, to confirm collection succeeds cleanly.
- Ledger history (25 rows, 22 patterns) is real but sparse and carries no per-memory
  grades — used only for cadence/provenance, never for synthesizing a grade (spec §2).
